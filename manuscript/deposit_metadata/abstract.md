In Alaska and northwestern Canada, field data on vegetation composition and structure remain fragmented across jurisdictional boundaries. To address this gap, we developed the Alaska Vegetation Database (AKVEG): a harmonized, relational database of plot-level vegetation observations from 1975 to 2025. This repository contains the compiled data tables from v2.11.1 of the public database, exported as 16 comma-separated values (.csv) tables.

To build AKVEG, we integrated data from 100 survey and monitoring projects across Alaska and adjacent Canada. Using a  reproducible scripting workflow, we harmonized measurement units, documented methodological metadata, and reconciled field identifications to a taxonomic standard. The AKVEG Database comprises 701,216 records of foliar cover for vascular plants, bryophytes, and lichens from 44,324 unique site visits. 

This data deposit consists of 19 files:
* Tabular files (16 CSV files): Compiled tables exported from the live AKVEG Database. These include 4 reference tables and 12 data tables.
* Data Standards Protocol (VWG_2022_Minimum_Standards_v1_1.pdf): This document establishes data collection standards for field vegetation observations in Alaska, and defines the data schema that formed the basis for the AKVEG Database. The Minimum Standards were written by members of the Alaska Geospatial Council's Vegetation Working Group.
* User vignette & source code (akveg_vignette.Rmd & akveg_vignette.html): R Markdown source code and compiled HTML user guide to help researchers navigate the dataset and perform operations such as spatial filtering, table joining, and taxonomic reconciliation.

Spanning five decades, four bioclimatic zones, and two nations, this harmonized dataset supports vegetation mapping, community classification, and the modeling of plant community responses to environmental change.
