# AKVEG Taxonomy Changelog

All changes to the AKVEG taxonomic standard are documented in this file. Changes to the database (dataset additions, replacements, or removals) are documented in 
[CHANGELOG.md](CHANGELOG.md).

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## Unreleased

### Added 
* 1 functional group taxon: brown moss (hydrophytic).

### Fixed
* Corrected *Isoetes myurellum* to *Isothecium myurellum* (data entry error).

## [1.2] - 2026-02-18

### Added
* 2 new hybrid taxonomic records: *×Elyhordeum* and *×Elyhordeum macounii*.

## [1.1] - 2026-02-12

### Added
* 71 new taxonomic records, including 41 accepted species. Most of these taxa do not occur in Alaska but are required to support the ingestion of Canadian datasets.

## [1.0] - 2025-06-03

### Added
* Initial baseline of the AKVEG taxonomic standard.

## Versioning System

We use a MAJOR.MINOR versioning system:

1. *MAJOR*: Structural changes to the taxonomic schema.
2. *MINOR*: Add new taxa or fix typos.

This changelog was established on 2026-03-17. Entries prior to this date have been documented retroactively from archived versions of the master checklist.
