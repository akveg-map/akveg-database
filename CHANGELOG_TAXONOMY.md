# AKVEG Taxonomy Changelog

Changes to the AKVEG taxonomic standard are documented in this file. Changes to the codebase are documented in 
[CHANGELOG.md](CHANGELOG.md), while changes to the datasets and database schema are documented in the `database_version` table within the database.

This changelog was established on 2026-03-17. Entries prior to this date have been documented retroactively from archived versions of the master checklist.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

---

## 2026-10-23

### Added 
* 1 new taxonomic record: _Sphagnum miyabeanum_.

### Updated
- Listed _Sphagnum subsecundum_ as "taxonomy unresolved" instead of "accepted". Future taxonomic updates will 
  address updates to the _S. subsecundum_ group.

## 2026-03-17

### Added 
* 1 functional group taxon: brown moss (hydrophytic).

### Fixed
* Corrected *Isoetes myurellum* to *Isothecium myurellum* (data entry error).

## 2026-02-18

### Added
* 2 new hybrid taxonomic records: *×Elyhordeum* and *×Elyhordeum macounii*.

## 2026-02-12

### Added
* 71 new taxonomic records, including 41 accepted species. Most of these taxa do not occur in Alaska, but are 
  required to support the ingestion of Canadian datasets.
